# Ragent 核心规则

本目录保存不可随意改变的领域与运行时约束。它是需求、测试、配置和代码之间的共同契约，不是设计草稿的存放处。

## 应该记录的内容

- 检索通道的启用条件、候选合并、去重、重排与截断顺序；
- 意图分数、阈值、会话记忆窗口、限流和超时等影响对外行为的固定参数；
- 文档处理状态、重试、幂等、失败补偿与可观测性边界；
- 模型路由、熔断、降级和 MCP 调用的失败语义；
- 权限、数据隔离、审计与敏感信息处理规则。

## 编写和变更要求

- 规则应使用可验证的陈述，避免“适当”“尽量”一类不可测试的表述。
- 复杂规则必须提供顺序、示例、反例或伪代码，并指出受影响的配置和测试位置。
- 修改规则时，先更新本文档和相应验收用例，再调整实现与配置。
- 如果规则仅适用于临时实验，应写明生效范围、开关和移除条件，不能默认为全局行为。

当前检索链路的强约束见 [retrieval-invariants.md](retrieval-invariants.md)。
