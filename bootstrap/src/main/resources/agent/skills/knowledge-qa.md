---
name: 知识库问答
description: 校内制度、培养方案、通知类问题的标准处理流程
triggers: 规定, 政策, 制度, 流程, 要求, 条件, 材料, 培养方案, 通知
---
1. 先用 knowledge_search 检索：关键词取「对象 + 动作」，不要照抄整句问题。
2. 没有命中或命中明显不相关时，换更短、更具体的关键词再查一次（最多两次）。
3. 拿到资料后先判断是否直接回答了问题；资料只覆盖一部分时，明确说明哪部分能答、哪部分没有依据。
4. 回答时给出结论在前、依据在后，并说明来自哪份文档；不要输出工具的原始 JSON。
5. 仍然查不到时，如实说明「知识库里没有查到」，并告诉用户可以补充哪些信息（学院、年级、具体事项）。
