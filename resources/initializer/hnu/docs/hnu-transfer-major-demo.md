# 转专业与学籍异动（示例资料）

> 本文件是初始化器自带的**示例资料**，仅用于让新环境能立刻跑通「提问 → 检索 → 回答」。
> 真实落地时请用学校正式文件替换，或把 `scenario.properties` 的 `docs-dir` 指向你的资料目录。

## 转专业申请材料

1. 《学生转专业申请表》（一式两份，需本人签字、转出学院与转入学院分别签署意见）。
2. 成绩单（教务系统打印，含已修课程与绩点，需加盖学院教学公章）。
3. 个人陈述（说明转专业理由、对拟转入专业的了解与学习规划，800 字以内）。
4. 如有相关的竞赛获奖、项目经历或作品材料，可附复印件作为补充说明。

## 受理时间与流程

- 每学年集中受理一次，通常在**春季学期第 8—10 周**，具体时间以教务处通知为准。
- 流程：学生提交材料 → 转出学院审核 → 转入学院考核（笔试或面试） → 教务处公示 → 学籍异动生效。
- 获准转专业的学生，已修课程按《课程替代与学分认定办法》办理学分认定，未通过认定的课程需补修。

## 常见限制

- 转专业仅限一年级、二年级学生申请；毕业年级与休学期间不受理。
- 部分专业对数学、外语等基础课程成绩有最低要求，以当年《转专业实施细则》为准。
- 同一学生原则上在校期间只允许转专业一次。
